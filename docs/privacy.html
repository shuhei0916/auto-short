Privacy Policy

Last updated: 2026-11-23

"Bounce Theory uploader" (the "App") is a personal tool used only by the owner of the YouTube channel Bounce Theory to upload videos to that channel and read its statistics. It is not offered to the public.

Data the App accesses

With the owner's consent through Google OAuth, the App uses these YouTube API scopes:

  • youtube.upload: to upload and schedule videos on the owner's channel.
  • youtube.readonly: to read the channel's own video list and basic statistics.
  • yt-analytics.readonly: to read the channel's own analytics (views, retention, subscribers).

How the data is used and stored

  • Data is used only to upload the owner's videos and to measure how those videos perform.
  • Aggregated channel statistics are saved in the App's source repository. No personal information about viewers is collected.
  • The OAuth token is stored as an encrypted secret in the owner's GitHub repository and is never shared.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The App also uses YouTube API Services; see the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through GitHub issues or the support email shown on the App's Google consent screen.
